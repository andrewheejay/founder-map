What the map shows

    How it's built

    Paths. Each founder sits in one cluster for the main career path that led to this company, from public bios as of October 2026. A dashed stub points toward a second path that also fits.

    Open source is a badge, not a path. Prior open source means the founder created or co-created a notable project before this company (Envoy, Ray, Vagrant). Open source product is a company attribute: whether the core product is open, partial (open tooling or standard, commercial core), or closed.

    Big tech means Google, Facebook (Meta), Microsoft, Amazon, Apple, Twitter, Uber, Lyft, or Palantir. Big tech engineer is a path (years building inside a large company or agency, such as the NSA); Big tech alum is a badge (worked at one of the nine).

    Stations are employers and schools shared by two or more founders, plus every prior open source project; turn on One-off ties in Filters for the rest. Valuations and rounds are the latest public figures. Full bios and sources live in Amplify Portfolio: Founder Briefs.
